# Guidely Roadmap

## MVP (v0.1.0) ✅
- [x] User auth (email/password + Google OAuth)
- [x] Creator profiles with session types
- [x] Availability calendar
- [x] Booking system with slot management
- [x] Stripe Connect payments (configurable fee)
- [x] In-platform booking messaging
- [x] Jitsi video integration
- [x] Search/discover creators
- [x] Admin panel with analytics
- [x] Email reminders (cron-based)
- [x] Docker Compose deployment
- [x] OpenAPI/Swagger docs

## Post-MVP (v0.2.0 - v0.5.0)
- [ ] Two-way Google Calendar sync (CalDAV)
- [ ] Razorpay support for Indian market
- [ ] Group sessions / cohort-based offerings
- [ ] Creator payout analytics dashboard
- [ ] Verified review badges, response rate metrics
- [ ] Multi-currency support
- [ ] Webhook API for third-party integrations

## Future (v1.0+)
- [ ] Native mobile apps (React Native)
- [ ] Algorithmic discovery/recommendation layer
- [ ] Managed hosting offering
- [ ] Plugin/extension marketplace
